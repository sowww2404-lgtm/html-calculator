# 🧮 Bootstrap and HTML Calculator

A simple and responsive calculator developed using **HTML, CSS, Bootstrap 5, JavaScript, and jQuery**.

This project was developed as part of my **Web Development – Front-End** internship with **1Stop EduTech**.

## 📌 About the Project

The Bootstrap and HTML Calculator is designed to perform basic arithmetic operations through a clean and user-friendly interface.

The calculator provides a grid-based layout with buttons for numerical input and mathematical operations. JavaScript is used to handle user interactions and perform calculations in real time.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal number support
- ⌨️ Keyboard interaction
- 🖱️ Button-click interaction
- 🧹 Clear and delete operations
- 📱 Responsive Bootstrap-based layout
- 🧮 Displays the current input, expression, and result

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling and layout
- **Bootstrap 5** – Responsive user interface
- **JavaScript** – Calculator logic and operations
- **jQuery** – Supporting interactive functionality

## ⚙️ How It Works

1. The calculator interface is created using HTML and Bootstrap.
2. Buttons are arranged using a responsive grid layout.
3. Users can enter numbers and operators using the buttons or keyboard.
4. JavaScript processes the entered mathematical expression.
5. The calculated result is displayed on the calculator screen.
6. Clear and delete functions allow users to modify their input.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `vendor` folder.
3. Open `index.html` in a web browser.
4. The calculator will be ready to use.
